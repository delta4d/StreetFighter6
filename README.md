# Street Fighter 6 Combo Guide

Mobile-first combo reference for PS5 players using Modern controls, optimised for iPhone.

## Source

All combos are sourced from the YouTube video by **MENO**:

> ★【SF6】ルーク モダン コンボ集 / Luke Modern Combo Guide

MENO's guide uses numpad notation and covers no-meter through Super Art routes across all difficulty tiers. This repo translates that notation into PS5 DualSense button visuals (□ △ ○ ✕ R2 L1) for players who think in controller terms rather than arcade stick.

## Generated with Claude

The PS5 translation, HTML layout, and visual design were generated by **Claude** (Anthropic), working from MENO's original notation. Button mappings were verified against the official SF6 PS5 Modern control reference image.

## Structure

```
index.html                        ← character selector
assets/
  css/shared.css                  ← shared styles & PS5 button colours
  js/combo-ui.js                  ← accordion toggle
characters/
  luke/
    modern.html                   ← 23 combos, Beginner → Advanced
```

Adding a new character: create `characters/<name>/modern.html` using the same shared assets.
